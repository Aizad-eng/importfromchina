How to Find the HS Code (PCT Code) for Your Product in Pakistan

By importfromchina.shop teamUpdated October 3, 20267 min read
Quick answer

An HS code is the international six-digit classification for goods, and Pakistan extends it to an eight-digit PCT code in the Pakistan Customs Tariff. The code decides the customs duty rate, whether regulatory duty applies, whether the item is restricted and whether a CPFTA reduction exists. Find it in the FBR tariff, from the seller's export code, or from a clearing agent or import service, and confirm it before you pay.

What is an HS code and what is a PCT code?

The Harmonized System (HS) is a numbering scheme used by almost every customs authority in the world. The first six digits are the same everywhere: a mobile phone, a cotton T-shirt or a ball bearing has the same six digits in China, Pakistan and Germany. Each country then adds digits for its own tariff lines. Pakistan uses eight digits, and the result is called the Pakistan Customs Tariff (PCT) code. When a clearing agent asks for the HS code of your item, they mean the eight-digit PCT code that goes on the goods declaration.

How is the Pakistan Customs Tariff organised?

The tariff follows the HS structure. There are 21 sections and 97 chapters, grouped by type of material or product. Chapters 1 to 24 cover live animals, food and agricultural goods. Chapters 25 to 40 cover minerals, chemicals, plastics and rubber. Chapters 41 to 67 cover leather, textiles, clothing and footwear. Chapters 68 to 83 cover stone, glass, metals and metal articles. Chapters 84 and 85 cover machinery and electrical equipment, which is where most gadgets sit. Chapters 86 to 89 cover vehicles. Chapters 90 to 97 cover instruments, clocks, furniture, toys and miscellaneous articles. Each chapter is divided into headings (four digits), subheadings (six digits) and PCT lines (eight digits). The duty rate is set per PCT line.

How do I look up the code for my item?

  1. Search the FBR tariff. The Federal Board of Revenue publishes the Pakistan Customs Tariff as a searchable document and within WeBOC. Search by a plain description, then read the chapter notes, which define what belongs where.
  2. Ask the seller. Chinese exporters declare an HS code on their export paperwork. The first six digits transfer directly to Pakistan. The seller's code is a strong hint, not a final answer.
  3. Check a valuation ruling. If Pakistan Customs has issued a valuation ruling for your type of goods, the ruling names the PCT code it applies to. That is the code customs expects to see.
  4. Ask a clearing agent or an import service. They classify goods daily and know which codes customs accepts for common items.

Why does classification change the duty?

Pakistan sets customs duty per PCT line, with slabs that at the time of writing are commonly 0, 3, 11, 16 and 20 percent, and higher on some goods. Additional customs duty, regulatory duty and sales tax are then layered on top, and some of those also vary by code. Two items that look similar to a buyer can sit in different lines with different slabs. A part is often taxed differently from the finished machine it belongs to. An item of a given material may be taxed differently from the same item in another material. The code also determines whether a CPFTA reduction applies and whether the goods are restricted. What if two codes could apply?

The HS has rules for this, called the General Rules of Interpretation. In short: the more specific description wins over the general one; composite goods are classified by the component that gives them their essential character; and if that still does not settle it, the last code in numerical order applies. In practice, Pakistan Customs applies its own rulings and precedents, and the officer assessing your goods decides. If you declare a code and customs disagrees, the assessment is changed and duty is recalculated, which is one of the common reasons a parcel sits at the airport longer than expected. The process is described in how customs clearance works for air cargo.

Does the code affect anything other than duty?

  • Regulatory duty. Applied to a list of codes, often consumer goods and items with local manufacturing.
  • Restrictions. The Import Policy Order lists banned and restricted goods by code. Phones, drones, medicines and radio equipment carry conditions.
  • CPFTA. The China-Pakistan Free Trade Agreement reduces customs duty on listed codes with a Certificate of Origin. See how CPFTA works for buyers.
  • Valuation rulings. Issued per code, setting a minimum customs value.

Why confirm the code before ordering?

Because the code is the biggest single input to what you pay after the item price. Ordering first and classifying later is how people end up with a duty bill at the airport far above what they guessed. Frequently asked questions

What is the difference between an HS code and a PCT code?

HS is the international six-digit code. PCT is Pakistan's eight-digit extension of it in the Pakistan Customs Tariff. The first six digits are the same.

Where can I find the Pakistan Customs Tariff?

On the FBR website as a published tariff document, and within WeBOC. Clearing agents and import services also have it to hand.

Can I use the HS code the Chinese seller gives me?

The first six digits are a good starting point. Pakistan's eight-digit line and the duty rate still need to be checked against the current tariff and rulings.

What happens if I declare the wrong HS code?

Customs reassesses under the code it considers correct and recalculates duty. A deliberate misdeclaration can attract a penalty.

Does the HS code decide whether an item is allowed into Pakistan?

Partly. The Import Policy Order lists restrictions by code, so the code shows whether conditions such as PTA approval or prior permission apply.
