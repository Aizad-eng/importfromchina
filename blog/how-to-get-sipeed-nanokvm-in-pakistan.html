What is an IP-KVM and why would you want one?

KVM stands for keyboard, video, mouse. A normal KVM switch lets one keyboard and screen control two computers on the same desk. An IP-KVM goes further: it captures the computer's video output, pretends to be a USB keyboard and mouse, and puts all of that on your network. You open a browser on your laptop or phone and you are looking at the other computer's screen as if you were sitting in front of it.

The key difference from remote desktop software like AnyDesk or RDP is that an IP-KVM works below the operating system. You can see the computer boot, enter the BIOS, pick a boot drive, or fix a machine that crashed before Windows or Linux loaded. Remote desktop software cannot do any of that, because it only runs once the OS is up.

What do homelab users actually use the NanoKVM for?

  • BIOS and boot access: change BIOS settings or watch a server boot without plugging in a monitor.
  • Reinstalling an operating system remotely: the NanoKVM can pretend to be a USB flash drive and mount an installation image, so you can install Proxmox, TrueNAS or Windows on a machine in another room.
  • Power control: the Full version connects to the motherboard's power and reset header, so you can switch a frozen machine off and on from the browser.
  • Wake-on-LAN: wake other machines on the same network.
  • Remote access from outside the house: Sipeed lists Tailscale support, which lets you reach the NanoKVM over a private network without opening ports on your router.

If you run a small server at home, a mining rig, or a PC at your office or a relative's house that you look after, this is the job it does.

NanoKVM Lite vs Full vs Cube: which version should you pick?

This is where most buyers get confused. Sipeed's wiki describes two main versions, Lite and Full. Sipeed's GitHub page calls them NanoKVM-Cube Lite and NanoKVM-Cube Full, because the finished Full version comes in a small cube-shaped case. So when a listing says "Cube", it almost always means the Full kit in its case. The differences, from Sipeed's own comparison:

For a single unit, pick the Full version. The Lite saves a little money but you must supply and flash a microSD card, you have no screen to find its IP address, and you lose power control, which is one of the main reasons to own an IP-KVM.

Sipeed also sells other products under the NanoKVM name, including a PCIe version that mounts inside a PC case and a higher-spec NanoKVM-Pro. These are different products with different specs. Make sure the link you send matches the version you want.

How do you connect the NanoKVM Full?

  1. Connect an HDMI cable from the computer's video output to the NanoKVM's HDMI port.
  2. Connect a USB-C to USB-A data cable from the computer to the NanoKVM port Sipeed labels "HID Interface" or PC-USB. This is how it acts as a keyboard and mouse.
  3. Connect an Ethernet cable to your router or switch.
  4. For power control, connect the small KVM-B board to the motherboard's front-panel header and run a second USB-C cable to the port labelled ATX-Power. Your case's power button can be wired through it.
  5. If the PC cuts USB power when it shuts down, add 5V power to the AUX port so the NanoKVM stays on.
  6. Read the IP address on the OLED screen, open it in Chrome, and log in. The default username and password are admin and admin.
  7. Go to Settings, check for updates, install the latest version, and then change the password.

Is the NanoKVM safe to use?

This needs an honest answer. Independent researchers reported security problems in early NanoKVM firmware, including default credentials, SSH switched on by default, weak web security and an on-board microphone on some boards that was not clearly documented. Tom's Hardware reported that Sipeed says many of these issues are now addressed, though it could not verify every fix itself. Sipeed's quick start guide notes that SSH is disabled by default from version 1.4.0.

Sensible rules for any IP-KVM, this one included:

  • Update to the latest firmware before you rely on it.
  • Change the default admin password on day one.
  • Never expose the web interface directly to the internet with port forwarding. Use Tailscale or a VPN.
  • Keep it on your home network, ideally on a separate network segment if your router supports it.

What about power and load-shedding?

The NanoKVM runs on 5V and draws very little. Sipeed's guide warns that some low-quality chargers output 12V without proper negotiation and can damage the device, so use a standard 5V USB adapter or a proper PD charger. If you want to reach a machine after a power cut, the NanoKVM, your router and the computer all need to be on a UPS, and the computer's BIOS should be set to power on when mains returns. Otherwise you will be looking at a dark screen from a dead network.

Common mistakes with the NanoKVM

  • Buying the Lite and then finding you need a microSD card, a flashing tool and a way to find its IP address.
  • Using a charge-only USB cable for the HID connection, so the keyboard and mouse never appear.
  • Forgetting the second cable for ATX power control.
  • Leaving the default admin password in place.
  • Port-forwarding the web page to the internet instead of using Tailscale.

Frequently asked questions

What is the difference between NanoKVM Lite and Full?

The Lite is a bare board without a case, screen, ATX power control or system card. The Full adds all of these and works out of the box.

Is the NanoKVM Cube the same as the Full version?

Usually yes. Sipeed's GitHub calls the two kits NanoKVM-Cube Lite and NanoKVM-Cube Full, and the finished Full kit is the cube-shaped one. Check the listing says Full.

Can the NanoKVM access the BIOS?

Yes. It captures the HDMI output and acts as a USB keyboard, so it works from power-on, including BIOS and boot menus.

Do I need internet to use the NanoKVM?

No. It works on your local network through a browser. For access from outside, Sipeed lists Tailscale support.
